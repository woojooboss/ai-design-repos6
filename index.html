시작 전에 준비할 것

  • Claude Code가 설치되어 있어야 합니다.
  • Node.js 22 이상을 권장합니다.
    Awwwards MCP와 Brag가 22 이상을 요구합니다.
    터미널에서 node -v로 버전을 확인하세요.
  • 명령어는 두 종류입니다.
    터미널이라고 적힌 건 터미널에,
    Claude Code 안이라고 적힌 /plugin 줄은
    Claude Code 대화창에 입력합니다.
  • 설치한 뒤에는 Claude Code를 한 번 껐다 켜야
    새 도구를 인식합니다.

이 순서로 이어 쓰면 좋습니다

랜딩 페이지 하나를 만든다고 하면
여섯 개가 이렇게 이어집니다.

  1. 레퍼런스 찾기Awwwards MCP로 수상작 사이트를 찾아 방향을 잡습니다.
  2. 스타일 뽑기마음에 드는 사이트를 Dembrandt로 색·폰트·간격까지 뽑아 둡니다.
  3. 만들기Genjutsu가 시안을 먼저 보여 주고, 승인하면 코드를 씁니다.
  4. 화면 점검Responsively로 휴대폰·태블릿·PC에서 깨진 곳을 찾습니다.
  5. 알리기앱이면 App Store Screenshots로 스토어 이미지를,
    출시할 땐 Brag로 런치 영상을 만듭니다.
01

Awwwards MCP

AI가 수상작 사이트를 보고 배웁니다.

by INSANE0777★ 154MIT

웹 디자인 시상 사이트 Awwwards의 수상작을
실제 스크린샷과 함께 검색합니다.

마음에 드는 사이트의 색 팔레트, 기술 스택,
디자인 요소를 뽑아 주고,
2~5곳을 골라 디자인 브리프로 묶어 줍니다.

API 키도, 가입도 필요 없습니다.

설치

터미널에서 실행

claude mcp add awwwards -- npx -y awwwards-mcp

필요한 것

  • Node.js 22.13 이상
  • 사이트 실시간 캡처·움직임 녹화까지 쓰려면 playwright (선택)

이렇게 말해 보세요

awwwards에서 어두운 톤의 3D 포트폴리오 사이트를 찾아 줘. 그중 마음에 드는 3곳으로 내 포트폴리오 디자인 브리프를 만들어 줘.

02

Responsively App

화면 크기마다 깨진 곳을 한 번에 봅니다.

by responsively-org★ 25.3kAGPL-3.0

휴대폰·태블릿·PC 화면을
한 창에 나란히 띄우는 개발용 브라우저입니다.
한 화면에서 스크롤하거나 누르면
다른 기기 화면도 똑같이 따라 움직입니다.

MCP 서버가 들어 있어서
Claude Code가 직접 앱을 열고
기기별 스크린샷을 찍어 점검합니다.

설치 ① 앱

터미널에서 실행 (Windows / Mac 중 하나)

winget install ResponsivelyApp
brew install --cask responsively

설치 ② Claude Code 연결

터미널에서 실행

claude mcp add responsively -- npx -y @responsively/mcp

이렇게 말해 보세요

localhost:3000을 Responsively로 열어서 아이폰, 아이패드, PC 화면 스크린샷을 찍고 깨진 곳을 고쳐 줘.

앱을 설치한 뒤 한 번 실행해 두세요.
그다음부터는 Claude Code가 필요할 때 앱을 알아서 켭니다.

GitHub 열기 responsively-org/responsively-app
03

Genjutsu

AI가 습관처럼 쓰는 뻔한 디자인을 걸러 냅니다.

by AThevon★ 537MIT

스킬 세 개로 나뉩니다.

cast 버튼·카드 하나에 움직임 넣기
paint 제품 전체의 디자인 만들기
bunshin 에이전트 여러 명이 사이트 전체 만들기

코드를 쓰기 전에 방향을 먼저 보여 주고
승인을 받은 다음에 작업합니다.
똑같은 카드 세 장 같은 AI 기본값은
목록으로 관리하며 결과물에서 걸러 냅니다.

설치

Claude Code 안에서 한 줄씩 입력

/plugin marketplace add AThevon/genjutsu
/plugin install genjutsu

이렇게 말해 보세요

/genjutsu:paint 내 포트폴리오 사이트를 처음부터 만들어 줘.
/genjutsu:cast 가격표 카드에 마우스를 올리면 손에 잡힐 듯 움직이게 해 줘.

bunshin은 토큰을 많이 씁니다.
시작 전에 예상 비용을 알려 주고 두 번 확인을 받습니다.

Dembrandt

잘 만든 사이트의 디자인을 그대로 뽑아냅니다.

by dembrandt★ 3.7kMIT

사이트 주소 하나만 넣으면
로고, 색, 폰트, 간격, 그림자, 움직임을
디자인 토큰으로 정리합니다.
AI에게 넘기기 좋은 DESIGN.md로도 뽑아 줍니다.

함께 설치되는 dembrandt-skills에는
색 팔레트 만들기, 글자 크기 체계,
접근성 점검 같은 UX 지식 45가지가 들어 있어서
요청에 맞는 것을 AI가 알아서 꺼내 씁니다.

설치 ① 스킬 + MCP

Claude Code 안에서 한 줄씩 입력

/plugin marketplace add dembrandt/dembrandt-skills
/plugin install dembrandt@dembrandt

설치 ② 브라우저 (처음 한 번)

터미널에서 실행

npx dembrandt install-browser

이렇게 말해 보세요

stripe.com의 디자인 시스템을 뽑아서 내 랜딩 페이지에 같은 톤으로 적용해 줘.
이 화면의 사용성 문제를 점검해 줘.

브라우저 설치를 건너뛰면
사이트를 뽑을 때 'browser engine not available' 오류가 납니다.

06

Brag

다 만든 프로젝트를 런치 영상으로 바꿉니다.

by latent-spaces★ 16.5kMIT

프로젝트 폴더에서 명령어 하나면
음악과 모션, SNS에 올릴 소개 문구까지 들어간
짧은 출시 영상이 나옵니다.

결과물은 brag-output 폴더에
기획안, 공유 문구, brag.mp4로 저장됩니다.

설치

Claude Code 안에서 한 줄씩 입력

/plugin marketplace add latent-spaces/brag
/plugin install brag@brag

필요한 것

  • Node.js 22 이상, ffmpeg

이렇게 말해 보세요

let's /brag
/brag --tone "2016년 스타트업 투자 유치 발표처럼"

내레이션은 기본으로 꺼져 있습니다. 켜려면 /brag --voice
직접 돌리기 번거로우면 letsbrag.app에
사이트 주소만 붙여 넣어도 20초 영상을 받을 수 있습니다.
